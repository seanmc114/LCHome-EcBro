How the HL Home Ec exam is marked

Long Questions (each worth 80 marks)
Each long question has multiple parts (a, b, c...). Each part carries a set number of marks. Within each part, marks go to named points (stating the fact) and developed points (explaining or expanding it). A named point gets partial marks. A named and developed point gets full marks.

The examiner rewards: accuracy, use of correct terminology, relevant detail, and clear application to the question asked.
Short Questions (Section A, 100 marks)
10 short questions worth 10 marks each. Each has 2–3 sub-questions. These test precise knowledge — one or two correct key terms or facts per sub-question. No development required. Every mark counts here.
The golden rule
Every answer needs the correct term first, then the development. Writing "it is good for you" without naming the nutrient or process gets zero. Name it, then explain it. Every time.
